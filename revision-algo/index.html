    Algorithme, Python et variables

    Algorithme : suite d'instructions permettant la résolution d'un problème en un nombre fini d'étapes. À partir de données (les entrées), on parvient à un résultat (la sortie).

    Pourquoi Python 3 ?

    • Syntaxe simple et mode console pour tester immédiatement.
    • Langage interprété : les instructions sont exécutées au fur et à mesure. Un langage compilé traduit d'abord tout le programme en langage machine. Conséquence : un programme Python s'exécute jusqu'à la première erreur.
    • Haut niveau : pas de gestion de la mémoire à faire.
    • Structures de données évoluées (listes, ensembles, dictionnaires), open source, beaucoup de bibliothèques.

    Variables et types

    Une variable est un nom qui désigne une donnée susceptible de changer. Elle a un type qui fixe les valeurs possibles et les opérations permises.

    • Typage dynamique : on ne déclare pas le type, l'interpréteur le déduit à l'affectation.
    • Typage fort : les opérations possibles dépendent du type (on ne peut pas faire 3 + 'b').
    a = 3        ; print(type(a))    # int
a = 3.5      ; print(type(a))    # float
a = 'Campus' ; print(type(a))    # str
a = True     ; print(type(a))    # bool
b = 4/2      ; print(type(b), b) # float 2.0 : / donne TOUJOURS un float

    Transtypage (conversion de type)

    print(int(3.84))        # 3   → int() TRONQUE, il n'arrondit pas
print(round(3.84, 1))   # 3.8
print(round(3.84))      # 4
print(int('1234') + 1)  # 1235 : str → int
print(str(123) + '4')   # '1234' : int → str puis concaténation
    int('Campus') → ValueError (le texte n'est pas un nombre). 3 + 'b' → TypeError (types incompatibles). Mais 3 * 'b' → 'bbb' (répétition).

    Sous-programmes : fonctions et procédures

    Un sous-programme est un bloc d'instructions nommé, exécuté quand on l'appelle. Le programme principal se suspend, exécute le sous-programme, puis reprend.

    Procédure : modifie l'état du programme (affiche, modifie une liste…) sans retourner de résultat.
    Fonction : retourne un résultat avec return.
    def calcul_aire(longueur, largeur):   # FONCTION : renvoie une valeur
    return longueur * largeur

def table_de_multiplication(valeur):  # PROCÉDURE : affiche, ne renvoie rien
    for i in range(0, 11):
        print(valeur, 'x', i, '=', i*valeur)

print(calcul_aire(10, 5))
table_de_multiplication(9)

    Trois avantages (question de cours classique)

    1. Éviter la duplication de code : un bloc utilisé à plusieurs endroits est écrit une seule fois.
    2. Favoriser la réutilisation : on peut créer des bibliothèques de sous-programmes.
    3. Améliorer la conception : découper un problème en sous-problèmes plus simples (hiérarchie de tâches).

    assert : protéger le domaine de définition

    def fact(n):
    assert n >= 0 and int(n) == n, "La factorielle n'existe pas !"
    if n == 0 or n == 1:
        return 1
    return n * fact(n-1)
print(fact(5))

    assert condition, message lève une AssertionError si la condition est fausse. C'est l'étape 3 de la méthode récursive (le « cas non voulu »).

    return arrête immédiatement la fonction. Une fonction sans return renvoie None. Ne confonds pas print (affiche) et return (renvoie).

    Listes en compréhension

    On applique une opération à chaque élément d'une séquence pour construire une liste, en une ligne : [expression for x in séquence if condition].

print([(i, j) for i in range(1, 5) for j in range(i+1, 5)])  # sans doublons

    Morpion : tester la victoire

    Il y a 8 alignements : 3 lignes, 3 colonnes, 2 diagonales. La case ne doit pas être vide (≠ 0).

    def test(t):
    for i in range(3):   # colonnes
        if t[0][i] == t[1][i] == t[2][i] != 0:
            return True
    for i in range(3):   # lignes
        if t[i][0] == t[i][1] == t[i][2] != 0:
            return True
    if t[0][0] == t[1][1] == t[2][2] != 0:   # diagonale
        return True
    if t[0][2] == t[1][1] == t[2][0] != 0:   # anti-diagonale
        return True
    return False

print(test([[0, 2, 1], [0, 1, 0], [1, 0, 2]]))   # True (anti-diagonale de 1)

    Deviner un nombre et Monte-Carlo

    from random import randint puis randint(1, 100) donne un entier entre 1 et 100 inclus. random() donne un float dans [0 ; 1[. Monte-Carlo : on tire des points au hasard dans un carré de côté 1 ; la proportion de points dans le quart de cercle (x² + y² ≤ 1) tend vers π/4.

    from random import random
dedans = 0
N = 20000
for i in range(N):
    x, y = random(), random()
    if x*x + y*y <= 1:
        dedans = dedans + 1
print(4 * dedans / N)   # ≈ 3.14, convergence très lente

    Récursivité

    Sous-programme récursif : un sous-programme qui s'appelle lui-même. On ramène le problème à un problème similaire mais plus petit, jusqu'à un problème élémentaire dont on connaît la solution. Par opposition, un sous-programme qui ne s'appelle pas est itératif.

    Les problèmes intermédiaires sont stockés dans une pile (on y accède dans l'ordre inverse de leur ajout). Image du TD : les poupées russes, on ouvre jusqu'à la plus petite.

    Écrire une fonction récursive en 3 étapes

    1. Cas récursif (relation de récurrence) : n! = n × (n−1)!
    2. Cas de base (critère d'arrêt) : 0! = 1 et 1! = 1
    3. Cas non voulu (contrainte) : factorielle(−1) ? factorielle(1.5) ? → assert
    def factorielle(n):
    assert n >= 0 and int(n) == n, 'n doit être entier positif ou nul'  # étape 3
    if n in [0, 1]:                                                    # étape 2
        return 1
    return n * factorielle(n-1)                                        # étape 1
print(factorielle(4))

    Trace de factorielle(4) : la pile d'appels

    factorielle(4) = 4 * factorielle(3) ← empilé 3 * factorielle(2) ← empilé 2 * factorielle(1) ← empilé 1 ← cas de base atteint, on dépile 2 * 1 = 2 3 * 2 = 6 4 * 6 = 24 → 24
    Sans cas de base (ou si on ne s'en rapproche jamais), la fonction s'appelle à l'infini → RecursionError: maximum recursion depth exceeded.

    Récursif ou itératif ? (tableau du TD)

    CritèreRécursifItératifPourquoi
    Économe en mémoire ?NonOuila récursion utilise la pile
    Rapide ?NonOuiempiler/dépiler les appels coûte du temps
    Facile à écrire ?OuiNonquand le problème se découpe en sous-problèmes similaires

    On peut toujours transformer un algorithme récursif en itératif et inversement. La récursivité est indispensable sur les structures complexes : listes, arbres, graphes.

    Puissance xⁿ

    def puissance(x, n):            # xⁿ = x × xⁿ⁻¹ ; x⁰ = 1
    assert n >= 0 and int(n) == n
    if n == 0:
        return 1
    return x * puissance(x, n-1)

def puissance_iter(x, n):
    resultat = 1
    for _ in range(n):          # _ : variable inutilisée
        resultat = x * resultat
    return resultat

def puissance_rapide(x, n):     # diviser pour régner : O(log n)
    if n == 0:
        return 1
    m = puissance_rapide(x, n // 2)
    if n % 2 == 0:
        return m * m
    return x * m * m

print(puissance(2, 10), puissance_iter(2, 10), puissance_rapide(2, 10))

    Fibonacci (récursivité multiple)

    Quand une fonction s'appelle plusieurs fois, on parle de récursivité multiple. Attention à la convention du prof : fibo(0) = fibo(1) = 1, donc fibo(5) = 8.

    def fibo(n):
    if n == 0 or n == 1:
        return 1
    return fibo(n-1) + fibo(n-2)      # 2 appels → O(2ⁿ)

def fibo_iteratif(n):
    a, b = 1, 1
    for _ in range(n):
        a, b = b, a + b               # affectation simultanée
    return a                          # O(n)

print(fibo(5), fibo_iteratif(5))

    if k == 0 or k == n:

    return binomial(n-1, k-1) + binomial(n-1, k)   # triangle de Pascal
print(binomial(4, 2), binomial(10, 3))

    Conversion décimal → binaire

    def conversion(n):
    if n == 0:
        return 0
    return n % 2 + 10 * conversion(n // 2)

def conversion_iter(n):           # le « petit défi » du TD
    if n == 0:
        return '0'
    bits = ''
    while n > 0:
        bits = str(n % 2) + bits  # on ajoute le reste devant
        n = n // 2
    return bits

print(conversion(42), conversion_iter(42))   # 101010

    Algorithmes de tri et recherche dichotomique

    Objectif : réordonner une liste de nombres par ordre croissant, sur place (sans liste intermédiaire, pour économiser la mémoire). Le cours annonce 5 tris : 3 itératifs (sélection, bulles, insertion) et 2 récursifs (fusion, rapide).

    Recherche dichotomique (tableau TRIÉ)

    On compare avec l'élément du milieu et on élimine la moitié du tableau à chaque étape. Taille 16 → 8 → 4 → 2 → 1 : 2ᵏ = N donc k = log₂N étapes.

    def dichotomie(tab, x):
    debut, fin = 0, len(tab) - 1
    while debut <= fin:
        milieu = (debut + fin) // 2
        if tab[milieu] == x:
            return milieu
        elif tab[milieu] < x:
            debut = milieu + 1      # on garde la moitié droite
        else:
            fin = milieu - 1        # on garde la moitié gauche
    return -1                       # absent

print(dichotomie([1, 5, 8, 9, 11, 13, 15, 19, 21], 9))   # 3

    Tri par sélection

    Pour chaque position i, on cherche le minimum de la partie non triée et on l'échange avec tab[i].

    def tri_selection(tab):
    n = len(tab)
    for i in range(n - 1):
        imin = i
        for j in range(i + 1, n):
            if tab[j] < tab[imin]:
                imin = j
        tab[i], tab[imin] = tab[imin], tab[i]   # échange
    return tab
print(tri_selection([5, 1, 4, 2, 8]))

    Tri à bulles

    On compare les éléments voisins et on les échange s'ils sont mal rangés. Après chaque passage, le plus grand élément « remonte » à la fin.

    def tri_bulles(tab):
    n = len(tab)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if tab[j] > tab[j+1]:
                tab[j], tab[j+1] = tab[j+1], tab[j]
    return tab
print(tri_bulles([5, 1, 4, 2, 8]))

    Tri par insertion

    Comme quand on range des cartes en main : on prend chaque élément et on l'insère à sa place dans la partie déjà triée à sa gauche.

    def tri_insertion(tab):
    for i in range(1, len(tab)):
        cle = tab[i]
        j = i - 1
        while j >= 0 and tab[j] > cle:
            tab[j+1] = tab[j]     # décale vers la droite
            j = j - 1
        tab[j+1] = cle
    return tab
print(tri_insertion([5, 1, 4, 2, 8]))

    Tri fusion (diviser pour régner)

    On coupe la liste en deux, on trie chaque moitié récursivement, puis on fusionne deux listes triées.

    def fusion(a, b):
    res = []
    i, j = 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            res.append(a[i]); i = i + 1
        else:
            res.append(b[j]); j = j + 1
    return res + a[i:] + b[j:]

def tri_fusion(tab):
    if len(tab) <= 1:
        return tab
    m = len(tab) // 2
    return fusion(tri_fusion(tab[:m]), tri_fusion(tab[m:]))
print(tri_fusion([6, 3, 9, 8, 5, 1]))

    Tri rapide (quicksort)

    On choisit un pivot, on place à gauche les éléments plus petits et à droite les plus grands, puis on trie récursivement chaque côté.

    def tri_rapide(tab):
    if len(tab) <= 1:
        return tab
    pivot = tab[-1]
    gauche = [x for x in tab[:-1] if x < pivot]
    droite = [x for x in tab[:-1] if x >= pivot]
    return tri_rapide(gauche) + [pivot] + tri_rapide(droite)
print(tri_rapide([6, 3, 9, 8, 5]))

    Fiche 10 · TD complexité

    Complexité algorithmique

    Big O est la métrique utilisée pour décrire l'efficacité d'un algorithme : comment le nombre d'opérations grandit quand la taille n des données grandit. Exemple du TD : peindre un mur de largeur w et hauteur h → O(w × h).

    Pire cas, cas moyen, meilleur cas

    • Big O : borne du pire cas (complexité inférieure ou égale au pire cas).
    • Big Ω (Oméga) : borne du meilleur cas.
    • Big Θ (Thêta) : présenté en TD comme la complexité « médiane » entre pire et meilleur cas.

    Exemple : rechercher une valeur en parcourant un tableau de n cases → O(n) (elle est à la fin ou absente), Ω(1) (elle est en première case), Θ(n/2) en moyenne.

    Les classes de complexité

    Ordre à retenir (de la meilleure à la pire) : O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!).

    Exemples corrigés du TD

    findBiggestNumber → O(n)

    def findBiggestNumber(sampleArray):
    biggestNumber = sampleArray[0]                    # O(1)
    for index in range(1, len(sampleArray)):          # O(n)
        if sampleArray[index] > biggestNumber:        #   O(1)
            biggestNumber = sampleArray[index]        #   O(1)
    print(biggestNumber)                              # O(1)
findBiggestNumber([5, 4, 10, 8, 11, 68, 87])
# O(1) + O(n) + O(1) → O(n)

    Fonction récursive simple → O(n)

    def findMaxNumRec(sampleArray, n):          # M(n)
    if n == 1:                              # O(1)
        return sampleArray[0]               # O(1)
    return max(sampleArray[n-1], findMaxNumRec(sampleArray, n-1))   # M(n-1)
print(findMaxNumRec([5, 4, 10, 8, 11, 68, 87, 10], 8))

    On pose M(n) = O(1) + M(n−1) et M(1) = O(1). En déroulant : M(n) = 1 + M(n−1) = 2 + M(n−2) = … = a + M(n−a). Avec a = n−1 : M(n) = n − 1 + M(1) = n. Donc O(n).

    Fonction à double appel récursif → O(2ⁿ)

    def f(n):
    if n <= 1:
        return 1
    return f(n-1) + f(n-1)
print(f(4))

    Arbre des appels : niveau 0 → 1 appel, niveau 1 → 2, niveau 2 → 4… soit 2⁰ + 2¹ + … + 2ⁿ⁻¹ = 2ⁿ − 1 appels → O(2ⁿ). Règle générale : O(branches^profondeur).

    Deux boucles successives → O(n)

    def foo(array):
    sum = 0                       # O(1)
    product = 1                   # O(1)
    for i in array:               # O(n)
        sum = sum + i
    for i in array:               # O(n)
        product = product * i
    print("Sum =", sum, ", Product =", product)
foo([1, 2, 3, 4])
# O(n) + O(n) = O(2n) → O(n)

    Deux boucles imbriquées → O(n²)

    def printPairs(array):
    for i in array:           # O(n)
        for j in array:       # O(n) pour CHAQUE i
            print(i, j)       # → O(n × n) = O(n²)
printPairs([1, 2, 3])

    Paires non ordonnées → O(n²) quand même

    def printUnorderedPairs(array):
    for i in range(0, len(array)):
        for j in range(i+1, len(array)):
            print(array[i], array[j])
printUnorderedPairs([1, 2, 3, 4])

    Méthode 1 (compter) : (n−1) + (n−2) + … + 2 + 1 = n(n−1)/2 = n²/2 − n/2 → O(n²). Méthode 2 (travail moyen) : la boucle externe fait n tours, la boucle interne fait en moyenne n/2 tours → n × n/2 = n²/2 → O(n²).

    Deux tableaux différents → O(a × b)

    def pairs(arrayA, arrayB):
    for i in range(len(arrayA)):              # a tours
        for j in range(len(arrayB)):          # b tours
            for k in range(0, 100000):        # constante ! O(1)
                pass
# O(a × b × 100000) → on supprime la constante → O(a × b)
    Ne pas écrire O(n²) quand les deux boucles parcourent deux tableaux différents : c'est O(a × b). Et une boucle de taille fixe (100 000, 10…) ne compte pas : c'est une constante.
